CHANNEL_HANDLE channel_create ( size_t  capacity)

Create a new channel with the specified capacity.

This function wraps the low-level syscall to allocate a channel. If capacity is 0, a default size (e.g., 4096 bytes) is used.

Parameters
capacityThe desired capacity of the channel buffer in bytes.
Returns
On success, returns a positive CHANNEL_HANDLE representing the channel. On error, returns negative errno: -ENOMEM : insufficient memory to allocate channel -EINVAL : invalid current unit or realm

Receive data from a channel.

Copies up to len bytes from the channel associated with the handle into the provided user buffer.

Parameters
hidCHANNEL_HANDLE of the channel to receive from.
bufPointer to a buffer where received data will be stored.
lenMaximum number of bytes to receive.
Returns
On success, returns the number of bytes actually received. On error, returns negative errno: -EINVAL : invalid channel handle or resource -EBADH : handle not found -EACCES : read capability missing -EAGAIN : channel is empty, try again later
