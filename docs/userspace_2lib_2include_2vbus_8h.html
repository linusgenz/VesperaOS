Read one complete vbus message (header + payload) from HANDLE_VBUS.

Reads the header into *hdr. If payload_buf is non-NULL and the message has a payload that fits, it is also read. Extra payload bytes are discarded.

Parameters
hdrOutput: filled with message header.
payload_bufBuffer for payload, or NULL to discard.
payload_capCapacity of payload_buf in bytes.
Returns
1 on success, 0 if channel empty (EAGAIN), <0 on error.

Subscribe to a vbus signal.

After this call, matching signals emitted by the kernel (or other senders) are written into HANDLE_VBUS. Use poll(HANDLE_VBUS, POLLIN) to wait.

Parameters
interfacee.g. VBUS_IFACE_POWER
membere.g. VBUS_SIG_BATTERY_CHANGED, or "" for all members
Returns
0 on success, negative errno on failure
