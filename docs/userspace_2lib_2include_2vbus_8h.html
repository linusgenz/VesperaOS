Sends a VBUS_MSG_CALL and records its serial in out_serial.

The caller must save *out_serial and match it against reply_serial in incoming VBUS_MSG_RETURN messages to identify the response.

Parameters
interfaceTarget interface name; must be non-NULL.
memberTarget method name; must be non-NULL.
sender_idRealmID of the sender
payloadCall arguments; may be NULL.
payload_sizeByte length of payload.
out_serialOutput: serial of the emitted CALL; must be non-NULL.
Returns
0 on success.
-EINVAL if interface, member, or out_serial is NULL.
Negative errno from vbus_emit_raw on failure.

Read one complete vbus message (header + payload) from HANDLE_VBUS.

Reads the header into *hdr. If payload_buf is non-NULL and the message has a payload that fits, it is also read. Extra payload bytes are discarded.

Parameters
hdrOutput: filled with message header.
payload_bufBuffer for payload, or NULL to discard.
payload_capCapacity of payload_buf in bytes.
Returns
1 on success, 0 if channel empty (EAGAIN), <0 on error.

◆ vbus_subscribe()

int vbus_subscribe ( const char *  interface,
const char *  member 
)

Subscribes the calling process to messages matching (interface, member).

After this call, matching messages are queued into HANDLE_VBUS. Use poll(HANDLE_VBUS, POLLIN) to wait for incoming messages.

Pass member as NULL or "" to receive every member on interface (wildcard).

Returns
0 on success, negative errno on failure.
