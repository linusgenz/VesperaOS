Detailed Description

LVGL v8 lv_img_dsc_t layout — mirrored here so callers need not include <lvgl/lvgl.h>. The bit-field order must match the LVGL v8 header exactly.

cf values used in VesperaOS: 4 = LV_IMG_CF_TRUE_COLOR (lv_color32_t per pixel, alpha in MSB) 5 = LV_IMG_CF_TRUE_COLOR_ALPHA (lv_color_t + separate alpha byte; 16-bit only)
