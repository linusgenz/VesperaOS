Detailed Description

Structure representing information about a Unit.

This structure is used when querying the state of a Unit within a Realm. A Unit is conceptually similar to a thread, running inside a Realm (which acts like a process). It contains runtime and scheduling information, resource handles, stack layout, and termination state.
