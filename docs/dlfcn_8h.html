Macro Definition Documentation

◆ RTLD_GLOBAL

#define RTLD_GLOBAL   0x0004

Make the library's symbols available to other libraries.

Passed as (part of) mode to dlopen(). Symbols become part of the global symbol scope and can satisfy references in libraries loaded afterwards.

◆ RTLD_LAZY

#define RTLD_LAZY   0x0001

Resolve symbols only when first referenced (lazy binding).

Passed as (part of) mode to dlopen(). Relocations for function symbols are deferred until the symbol is actually used.

◆ RTLD_LOCAL

#define RTLD_LOCAL   0x0000

Keep the library's symbols local to the handle (default).

Symbols are not made available for resolving references in subsequently loaded libraries.

◆ RTLD_NOW

#define RTLD_NOW   0x0002

Resolve all symbols immediately when the library is loaded.

Passed as (part of) mode to dlopen(). If any symbol cannot be resolved, dlopen() fails.

◆ dlclose()

int dlclose ( void *  handle)

Release a handle previously obtained from dlopen().

Decrements the library's internal reference count. Once it reaches zero, the library's destructors are run and its mappings are released. handle must not be used again afterwards.

Parameters
handleHandle returned by dlopen().
Returns
0 on success, or a negative error code on failure.

Return a description of the most recent dlopen()/dlsym()/ dlclose() failure on the calling unit.

Each call consumes the stored error: if no error occurred since the last call to dlerror(), NULL is returned.

Returns
Null-terminated, human-readable error string, or NULL if there is no pending error.

◆ dlopen()

void * dlopen ( const char *  path,
int  mode 
)

Load a shared library and map it into the calling unit's address space.

Parses the ELF image at path, maps its segments, resolves its dependencies, applies relocations and (depending on mode) runs its constructors. Repeated calls with the same path return the same handle and increment an internal reference count.

Parameters
pathPath to the shared library (e.g. "/lib/libm.so"). Must not be NULL.
modeBitwise OR of exactly one of RTLD_LAZY / RTLD_NOW, optionally combined with RTLD_GLOBAL.
Returns
Opaque handle to be passed to dlsym() / dlclose() on success, or NULL on failure. Use dlerror() to retrieve the reason.
