Map pages into the process address space.

Parameters
addrDesired address (may be 0 for automatic placement).
lengthLength of mapping in bytes (rounded up to page size).
protProtection flags (PROT_READ, PROT_WRITE, PROT_EXEC).
flagsMapping flags (MAP_PRIVATE, MAP_SHARED, MAP_ANONYMOUS, ...).
handleFile descriptor or handle (if MAP_ANONYMOUS not set, otherwise ignored).
offsetOffset in file (must be multiple of page size).
Returns
On success: pointer to mapped memory. On error: (void*) -1 with errno set.
