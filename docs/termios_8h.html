Read the current mode of a TTY device.

Queries the TTY associated with tty and fills t with its current mode and echo settings.

Parameters
ttyFile handle referring to the TTY device (usually stdin).
tPointer to a tty_mode_t struct to be filled on success.
Returns
0 on success, negative error code on failure.

Apply a mode change to a TTY device.

Sets the operating mode and echo behavior of the TTY associated with tty. Switching between TTY_MODE_CANONICAL and TTY_MODE_RAW drains any pending input so the new mode starts clean.

Parameters
ttyFile handle referring to the TTY device (usually stdin).
tPointer to a tty_mode_t struct describing the desired mode.
Returns
0 on success, negative error code on failure.

inlinestatic

Query the dimensions of a TTY device.

Fills s with the current number of rows and columns visible in the terminal. The values reflect the physical character grid of the framebuffer terminal and do not change at runtime unless the font is switched.

Parameters
ttyFile handle referring to the TTY device (usually stdin).
sPointer to a tty_size_t struct to be filled with row and column counts on success.
Returns
0 on success, negative error code on failure.
