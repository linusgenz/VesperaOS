Adjust the program break (end of heap) for the current unit.

This syscall sets the end of the user heap to the specified address. If addr is 0, it simply returns the current break.

Parameters
arg0New desired end of heap (0 to query current break)
Returns
On success, returns the new program break. On error, returns negative errno: -EACCES : when unit is no user unit (this error should never be thrown) -EINVAL : addr is below heap start or exceeds limit -ENOMEM : not enough memory to expand

Change the permission mode bits of a file by path.

Only the file owner or root may change the mode. The setuid/setgid bits in arg1 are silently cleared for non-root callers if the file's group does not match the caller's egid.

Parameters
arg0Pointer to a null-terminated path string (user address).
arg1New mode bits (lower 12 bits used: setuid, setgid, sticky, rwxrwxrwx).
Returns
On success, returns 0. On error, returns negative errno: -EINVAL : path is null -ESRCH : no current realm found -ENOENT : path does not exist -EPERM : caller is not the file owner or root

This operation is not supported for directories or TTY devices.
