typedef struct __dirstream DIR

Opaque directory stream handle.

The layout is deliberately not exposed in this header (POSIX only requires that DIR be an incomplete/opaque type to callers). See internal/dirstream.h for the actual definition.

◆ readdir()

dirent_t * readdir ( DIR *  dirp)

Read the next directory entry from dirp.

The returned pointer refers to storage owned by dirp and is only valid until the next call to readdir() or closedir() on the same stream; it must not be freed by the caller.

Parameters
dirpOpen directory stream (see opendir()).
Returns
Pointer to the next dirent_t, or NULL at end-of-directory or on error. To distinguish the two, errno is left unchanged by readdir() on end-of-directory and is set to a nonzero value on error (check errno == 0 before the call if this matters).

◆ rewinddir()

void rewinddir ( DIR *  dirp)

Rewind a directory stream back to the first entry.

Note
VesperaOS's sys_readdir() has no native seek/rewind primitive yet. This is implemented by closing and re-opening the underlying handle at the same path. Any fd obtained via fdopendir() therefore cannot be rewound (see rewinddir() implementation note) and rewinddir() is a no-op with errno set to EBADF in that case.
