◆ fb_blit_t

typedef struct fb_blit fb_blit_t

Describes a rectangular pixel buffer transfer (blit) operation.

Copies a rectangular region from a source pixel buffer in userspace to the framebuffer.

All pixels are expected to use ARGB format (0xAARRGGBB).
