ssize_t getrandom ( void *  buf,
size_t  buflen 
)

Read random bytes from /dev/urandom into the provided buffer.

This function attempts to open /dev/urandom and fill buf with buflen random bytes. The read is performed in a loop to tolerate partial reads until the buffer is full or an error occurs.

Parameters
bufPointer to the destination buffer to fill with random data.
buflenNumber of bytes to read into the buffer.
Returns
On success: number of bytes actually read (should equal buflen). On failure: negative error code (-EINVAL, -ENOENT, -EIO).

◆ urandom_u32()

int32_t urandom_u32 ( void  )

Generate a 32-bit random unsigned integer.

This function reads 4 random bytes from /dev/urandom and returns them as a 32-bit value. In case of an error, the negative error code is returned as the function result.

Returns
On success: a random 32-bit integer. On failure: a negative error code (e.g., -ENOENT, -EIO).
