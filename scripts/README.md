# VesperaOS Build Scripts

## Commands Reference

| Command | Description |
|---------|-------------|
| `configure` | Configure build, patch limine, generate headers |
| `build` | Compile kernel and userspace |
| `clean` | Remove build artifacts |
| `disk` | Create bootable disk image |
| `run` | Launch QEMU |
| `debug` | Launch QEMU with GDB stub |
| `flash` | Write image to USB |
| `limine-patch` | Manually patch limine.h |
